# Function Machine Visualiser

## What this project does

This project shows how mathematical functions work like input-output machines.
The user chooses a function, enters a number, and the program calculates the output.

## Functions included

- f(x) = 2x + 3
- g(x) = xˆ2 - 4
- h(x) = 3x - 1
- g(f(x))
- f(g(x))

## What I learned

I learned that a function takes an input, follows a rule, and produces an output.
I also learned that function composition works like a pipeline. In g(f(x)), the
input goes through f first, then g.

## How to run the project

Run:
python main.py

## Example output

Input: 5.0
First machine: f(x) = 2x + 3
Middle output: 13.0
Second machine: g(x) = xˆ2 - 4
Final output: 165.0

## Why this matters

Functions are important in mathematics, coding, AI, robotics, and science because
they describe how inputs become outputs.
